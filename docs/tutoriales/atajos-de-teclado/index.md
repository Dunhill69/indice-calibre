# Atajos de teclado

:material-account: [Walter](https://t.me/Dunhill69){ target=_blank } · :material-link-variant: [Ver el original en Telegraph](https://telegra.ph/Atajos-de-Teclado-08-15){ target=_blank }
{ .tut-datos }

---

Acá les dejo una lista de atajos de teclado para usar en calibre y hacer su uso más fácil:

<br>

A: Añadir nuevos libros.

C: Convertir los libros ya seleccionados.

D: Enviar el libro al dispositivo por defecto.

Supr : Eliminar los libros seleccionados.

E: Modificar los metadatos de los libros seleccionados.

G: Obtener nuevos libros.

I: Mostrar los detalles de un título.

K : Modificar el índice.

F2: Modificar los metadatos del campo que está seleccionado en la lista.

O: Abrir la carpeta que contiene el libro marcado.

S: Guardar en el disco.

T: Modificar un libro.

V: Mostrar el libro marcado para su lectura.

Alt + V: Mostrar un formato de libro en concreto.

Alt + A: Mostrar libros del mismo autor que el actual.

Alt + T: Mostrar libros con las mismas etiquetas que el actual.

Alt + P: Mostrar libros de la misma editorial que el actual.

Alt + Mayús + S: Mostrar los libros de la misma serie que el actual.

Ctrl + Esc: Limpiar la biblioteca virtual que hemos creado.

Ctrl + flecha derecha: Seleccionar la siguiente pestaña de la biblioteca virtual.

Ctrl + D: Descargar los metadatos y las portadas de los títulos.

Ctrl + R: Reiniciar Calibre.

Ctrl + Mayús + R: Reiniciar Calibre en modo de depuración.

Ctrl + Q: Salir de calibre.

Ctrl +A Selecciona todos libros (en linux)

Ctrl +E Selecciona todos libros (en Windows)
