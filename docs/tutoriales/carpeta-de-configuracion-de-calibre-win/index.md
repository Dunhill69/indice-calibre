En Windows 10:

Está en esta ruta  C:\\Users\\Usuario\\AppData\\Roaming\\calibre   \<==== copiar esta carpeta para mantener toda la configuración de Calibre cuando se instala de nuevo ir a esa ubicación y copiar todos los archivos y reiniciar Calibre. Usuario es el nombre del usuario que se designó en la instalación de windows.
