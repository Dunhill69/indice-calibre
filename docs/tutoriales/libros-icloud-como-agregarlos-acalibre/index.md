# Libros de iCloud, cómo agregarlos a Calibre

:material-account: [Walter](https://t.me/Dunhill69){ target=_blank } · :material-link-variant: [Ver el original en Telegraph](https://telegra.ph/Libros-iCloud-como-agregarlos-acalibre-12-21){ target=_blank }

Libros iBook en iPhone o MacBook Pro a calibre.

Explicado por @Joseba\_Ibarra

1) Copiar 'idaho.epub' de iCloud a la carpeta Descargas

2) Botón derecho \> 'Mostrar contenido del paquete'

3) Seleccionar todos los archivos

4) Botón derecho \> 'Comprimir'

5) Renombrar 'archivo comprimido.zip' a 'idaho.epub' (o 'nuevo.epub', es lo mismo)

Y sí: se abre, se lee y se puede modificar en calibre
